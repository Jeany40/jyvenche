## 1. Hierarchy & Database Access
Everything client-facing lives under the **Portal Index**. Operational data is managed in databases.

- **[CLIENTS]**: One record per company/person.
- **[PROJECTS]**: The core management object. Format: `Client — Project Type — Phase`.
- **[TASKS]**: Format: `[Category] Task summary`.
- **[INVOICES]**: Format: `INV-XXXX — Client — Project`.

## 2. Naming Conventions
- **Project**: `BlissPointWell — Website — Phase 1`
- **Invoice**: `INV-0007 — BlissPointWell — Website Phase 1`
- **Task**: `[Content] Provide services + pricing copy`
- **Portal Page**: `Client Portal — [Project Name]`

## 3. Communication Standards
Use "Luxury Minimalist" terminology in all documentation:
- **Discovery** instead of "Sales Call".
- **Strategic Roadmap** instead of "To-do List".
- **Technical Specifications** instead of "Coding Notes".
- **Drafting SOW** instead of "Writing Quote".
